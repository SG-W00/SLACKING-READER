# 摸鱼阅读器 - Electron桌面版

一个可以悬浮在IDE（如IntelliJ IDEA）上的小说阅读器，支持窗口自由调整大小、透明度调节、背景虚化等功能。

## 功能特点

### 🪟 窗口管理
- **独立桌面窗口**：可放置在桌面任意位置
- **自由调整大小**：支持拖拽窗口边缘调整大小
- **始终置顶**：默认置顶，可悬浮在IDE上方
- **无边框设计**：简洁的自定义标题栏

### 🎨 视觉效果
- **窗口透明度**：30%-100%可调，融入IDE环境
- **背景虚化**：0-30px模糊效果
- **背景图片**：支持自定义背景图
- **背景缩放**：50%-200%缩放调节

### 📝 阅读设置
- **字体大小**：12px-32px可调
- **文字颜色**：自定义颜色
- **行高调节**：1.2-2.5倍行高
- **阅读区透明度**：独立调节内容区透明度

### 📚 小说管理
- **TXT导入**：支持.txt格式小说
- **自动分章**：智能识别章节标题
- **章节导航**：上一章/下一章快速切换
- **快捷键**：左右方向键翻页

## 安装与运行

### 1. 安装依赖
```bash
npm install
```

### 2. 启动应用
```bash
npm start
```

### 3. 打包为可执行文件（可选）
```bash
npm run build-win
```

## 使用说明

1. **导入小说**：点击"导入"按钮，选择.txt文件
2. **调整窗口**：拖拽窗口边缘调整大小，拖拽标题栏移动位置
3. **打开设置**：点击"设置"按钮打开设置面板
4. **调节透明度**：设置窗口透明度，让阅读器融入IDE背景
5. **背景虚化**：增加虚化程度，使阅读区更加突出
6. **快速调整字体**：阅读器底部有快速字体大小滑块

## 快捷键

- `←`：上一章
- `→`：下一章
- `ESC`：关闭设置面板

## 推荐设置（配合IDEA）

为了让阅读器更好地融入IDEA环境，推荐以下设置：

- **窗口透明度**：80%-90%
- **背景虚化**：10-15px
- **阅读区透明度**：85%-90%
- **背景颜色**：IDEA编辑器背景色相近
- **文字颜色**：IDEA文字颜色相近

## 技术栈

- Electron：跨平台桌面应用框架
- 原生JavaScript：轻量级实现
- CSS3：现代化UI设计

## 注意事项

- 确保小说文件编码为UTF-8
- 首次运行需要下载Electron，可能需要几分钟
- 设置会自动保存到本地
