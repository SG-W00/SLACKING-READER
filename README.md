# 摸鱼阅读器 - Electron桌面版

一个可以悬浮在IDE（如IntelliJ IDEA）上的小说阅读器，支持窗口自由调整大小、透明度调节、背景虚化等功能。

## 功能特点

### 🪟 窗口管理
- **独立桌面窗口**：可放置在桌面任意位置
- **自由调整大小**：支持拖拽窗口边缘调整大小
- **始终置顶**：默认置顶，可悬浮在IDE上方
- **无边框设计**：简洁的自定义标题栏

### 🎨 视觉效果
- **窗口透明度**：30%-100%可调，融入IDE环境
- **背景虚化**：0-30px模糊效果
- **背景图片**：支持自定义背景图
- **背景缩放**：50%-200%缩放调节

### 📝 阅读设置
- **字体大小**：12px-32px可调
- **文字颜色**：自定义颜色
- **行高调节**：1.2-2.5倍行高
- **阅读区透明度**：独立调节内容区透明度
- **章节名伪装**：章节下拉显示为 `src/chapter_001.ts` 风格源码路径（设置面板可开关）
- **进度条**：视口底部 2px 细线显示全书阅读进度
- **段落级进度**：按段落记录阅读位置，恢复精准不漂移

### 📚 小说管理
- **TXT导入**：支持.txt格式小说
- **编码自适应**：自动检测 UTF-8 / GBK / UTF-16，网文 txt 直接打开不乱码
- **大文件优化**：正文不落 localStorage，章节按需读取，百万字全本秒开不卡死
- **自动分章**：智能识别"第X章"标题，超大单章自动切块
- **章节导航**：上一章/下一章快速切换、滚动到底二次确认翻章
- **快捷键**：方向键/全局快捷键翻页

### 🕵️ 摸鱼伪装
- **右键伪装**：窗口内右键一键把阅读内容替换为以假乱真的前端构建日志，再按恢复原位置（像素级）
- **Boss Key 托盘隐藏**：按 Boss Key（默认 `Alt+Q`）整个窗口消失，托盘只剩一个低调灰色图标；再按或点托盘恢复，隐藏前自动保存进度
- **失焦自动伪装**：切回 IDE 的瞬间内容自动模糊变淡、工具栏隐藏，聚焦即恢复
- **沉浸模式（H 键三态）**：
  1. `normal`：正常状态
  2. `immersive`：隐藏标题栏与工具栏，正文撑满全窗（顶部隐形拖动带移动位置、右下角斜纹角标调整大小）
  3. `borderless`：窗口背景完全透明，只剩正文文字，真正融入 IDE 终端
- **快捷键自定义**：Boss Key 与全局翻章键位可在设置面板切换
- **日志静默**：调试日志默认关闭，DevTools 不暴露阅读痕迹

## 安装与运行

### 1. 安装依赖
```bash
npm install
```

### 2. 启动应用
```bash
npm start
```

### 3. 打包为可执行文件（可选）
```bash
npm run build-win
```

## 使用说明

1. **导入小说**：点击"导入"按钮，选择.txt文件
2. **调整窗口**：拖拽窗口边缘调整大小，拖拽标题栏移动位置
3. **打开设置**：点击"设置"按钮打开设置面板
4. **调节透明度**：设置窗口透明度，让阅读器融入IDE背景
5. **背景虚化**：增加虚化程度，使阅读区更加突出
6. **快速调整字体**：阅读器底部有快速字体大小滑块

## 快捷键

| 按键 | 作用 | 说明 |
|---|---|---|
| `右键`（窗口内） | 内容伪装 / 恢复 | 一键切换为构建日志，再按像素级恢复原位置 |
| `Boss Key`（默认 `Alt+Q`） | 窗口隐藏 / 恢复 | 整窗消失到托盘，设置面板可换键位 |
| `H` | 沉浸模式三态循环 | 正常 → 沉浸（隐藏导航）→ 无边框（透明融入 IDE）→ 正常 |
| `Alt+Shift+←/→` | 全局上一章/下一章 | 应用失焦也生效，IDE 内盲操作（键位可自定义） |
| `←` / `→` | 上一章 / 下一章 | 窗口聚焦时生效 |
| `ESC` | 关闭设置面板 | |

## 推荐设置（配合IDEA）

为了让阅读器更好地融入IDEA环境，推荐以下设置：

- **窗口透明度**：80%-90%
- **背景虚化**：10-15px
- **阅读区透明度**：85%-90%
- **背景颜色**：IDEA编辑器背景色相近
- **文字颜色**：IDEA文字颜色相近

## 技术栈

- Electron：跨平台桌面应用框架
- 原生JavaScript：轻量级实现
- CSS3：现代化UI设计

## 注意事项

- 小说文件编码无需担心，UTF-8 / GBK / UTF-16 自动检测
- 全局快捷键（Boss Key / 翻章键）为系统级拦截，若与其他软件冲突请在设置面板换键
- 沉浸模式下标题栏隐藏：拖动窗口用顶部 8px 隐形拖动带，调整大小用右下角斜纹角标
- 首次运行需要下载Electron，可能需要几分钟
- 设置会自动保存到本地
